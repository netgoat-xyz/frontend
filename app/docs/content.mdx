# Netgoat Documentation

Welcome to the **Netgoat internal documentation**. Netgoat is a high-performance, self-hostable reverse proxy and edge routing engine designed to act as a resilient layer on top of Cloudflare, or as a standalone traffic manager. 

---

## 🏗️ System Architecture

Netgoat is highly distributed, decoupled, and designed for maximum fault tolerance. The core architecture relies on **four main components**, communicating strictly over typed APIs, WebSockets, and encrypted internal links.

### The Stack at a Glance

1. **Frontend Dashboard**: A robust Next.js application for configuration.
2. **WhiteDiamond (Control Plane)**: Central configuration broadcaster.
3. **PinkDiamond (Edge Proxy)**: High-speed Go reverse-proxy and engine.
4. **DuckValue (Distributed Data Store)**: A custom sharded TCP key/value DB.

> **Why decoupled?**
> If your MongoDB goes down, **WhiteDiamond** continues using its local SQLite cache. If **WhiteDiamond** goes down, your **PinkDiamond** edge nodes switch seamlessly into fallback mode and serve from their own local SQLite databases, guaranteeing **zero runtime downtime** for edge traffic.

## 🖥️ Component Deep Dives

### 1. Frontend & Configuration Layer

The user-facing dashboard is built gracefully with **Next.js (App Router)**, **React 19**, and **Tailwind CSS 4.0**. 

- **State Management:** Handled dynamically via Server Actions. 
- **Database Backend:** Updates are written directly to **MongoDB** using Mongoose, creating a single source of truth for global configuration.
- **Styling UI:** A heavily customized `shadcn/ui` foundation fused with Framer Motion, running a cohesive frosted-glass aesthetic. 

```tsx
// Example Server Action saving a proxy configuration from the UI
export async function saveProxyConfig(config: ProxyConfig) {
  await dbConnect();
  
  // Creates standard MongoDB event that WhiteDiamond listens to
  const result = await MongooseProxy.create(config);
  return { success: true, id: result._id };
}
```

### 2. WhiteDiamond (Control Plane)

**Location**: `WhiteDiamond/`  
**Tech**: Node.js, Express, WebSockets, SQLite

The control plane (`WhiteDiamond`) forms the reliable bridge between the Database and the Edge.
Instead of edge nodes constantly polling an external database, WhiteDiamond establishes a highly efficient **Change Stream** connection to MongoDB.

1. Watch MongoDB for new proxy configurations or Web Application Firewall (WAF) rules.
2. Persist the fetched configuration immediately into a powerful local **SQLite** database for high-speed local indexing. 
3. Push differential updates instantly over an encrypted **WebSocket Stream** to all connected edge nodes (PinkDiamond).

```typescript
// WhiteDiamond: MongoDB Change Stream Example
db.collection('domains').watch().on('change', async (change) => {
  if (change.operationType === 'insert') {
    const newDomain = change.fullDocument;
    
    // 1. Sync to local SQLite
    await sqlite.run('INSERT INTO domains (id, host) VALUES (?, ?)', [newDomain._id, newDomain.host]);
    
    // 2. Broadcast immediately over WebSocket to PinkDiamond nodes
    wsServer.broadcast({ type: 'DOMAIN_SYNC', payload: newDomain });
  }
});
```

### 3. PinkDiamond (The Edge Proxy Engine)

**Location**: `PinkDiamond/`  
**Tech**: Go (Golang), SQLite, Let's Encrypt / ACME

The absolute physical workhorse of the stack. PinkDiamond sits at the very edge of your network, receiving incoming HTTP/HTTPS and WebSocket traffic. It replaces legacy Fastify routers to bring immense concurrent speed to the layer.

- **WAF & Anti-DDoS:** Fast path parsing for bad actors and malformed headers.
- **Dynamic Routing:** Per-domain logic cached directly in memory and SQLite.
- **Auto SSL:** Automatic TLS termination for active domains.
- **Zero Trust:** Cloudflare origin validation handling.
- **Fallback Resilience:** Automatically falls back onto the local configuration cache if the WebSocket to WhiteDiamond fails.

```go
// Inside PinkDiamond: Simplified Fallback Loop
func (p *ProxyAgent) syncLoop() {
    for {
        msg, err := p.wsClient.ReadMessage()
        if err != nil {
             log.Warn().Msg("Disconnected from WhiteDiamond. Switching to Fallback Mode.")
             p.EnableFallbackCache(true)
             time.Sleep(ExponentialBackoff(retryCount))
             continue
        }
        
        // Disable fallback once connected and write cache
        p.EnableFallbackCache(false)
        p.UpdateConfig(msg)
    }
}
```

### 4. DuckValue (Internal Key/Value Store)

**Location**: `DuckValue/`  
**Tech**: Go (Golang), TCP

For high-speed horizontal communication (like shared Rate Limiting buckets and active Load Balancer states), PinkDiamond needs something faster than SQLite and decoupled from the Control Plane. 

Enter **DuckValue** — our custom-built, sharded, thread-safe TCP database.

- **Multicore Concurrency:** 24 keyspace shards out of the box.
- **Replication:** Multi-primary replication, meaning you can run three DuckValue nodes worldwide and they will distribute state instantly using `DUCKVALUE_REPL_TOKEN`.
- **Durability:** Asynchronous WAL (Write-Ahead Logging) persistence keeps your data safe across restarts without blocking critical path reading.

```bash
# Example DuckValue Interaction
duckvalue> table_create ratelimits
duckvalue> use ratelimits
duckvalue/ratelimits> set limit_ip_192 50
duckvalue/ratelimits> get limit_ip_192
```

> **Note:** TLS is enforced cluster-wide between DuckValue members by default.

## 🚀 Common Integrations & Flows

1. **Changing a Routing Rule**  
   User alters a destination via the Next.js frontend → Frontend updates MongoDB →
   `WhiteDiamond` catches the stream event and saves to SQLite →
   `WhiteDiamond` sends over WebSocket to all `PinkDiamond` edges →
   `PinkDiamond` updates memory, saving immediately to its SQLite.

2. **Incoming User Request**  
   User visits `proxy.domain.com` → Hits `PinkDiamond` → 
   Edge proxy checks Local SQLite cache (0.5ms latency) → 
   Rate limiter fires to `DuckValue` store →
   WAF logic is parsed → 
   Data is seamlessly routed to the real Origin.
